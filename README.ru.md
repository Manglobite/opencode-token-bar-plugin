# opencode-session-token-bar

[English](README.md) | [Русский](README.ru.md)

Сворачиваемая панель статистики токенов для TUI OpenCode. Она располагается
непосредственно над строкой ввода и рекурсивно агрегирует корневую сессию и все
её дочерние сессии.

## Возможности

- Агрегирует вход из кэша, вход вне кэша, выход и hit rate по полному дереву
  сессии.
- Группирует строки развёрнутой панели по точному кортежу
  `(agent, providerID, modelID)`.
- Изначально свёрнута. Клик по `^` разворачивает, по `v` сворачивает панель;
  состояние сохраняется в локальном KV-хранилище TUI.
- Накапливает активное время, пока любая участвующая сессия имеет статус
  `busy` или `retry`.
- Добавляет колонку `peak t/s` после `rate`: пиковая скорость стриминга по строке
  агент/провайдер/модель.
- Показывает текущую скорость стриминга открытой сессии в колонке model сводной
  строки, либо `0.0 t/s` в простое.
- Использует фиксированную ширину колонок токенов и обрезает имя агента/модели
  в узком терминале, поэтому числовые колонки не смещаются при обновлении.

## Установка

Это TUI-плагин: серверная часть и параметры времени выполнения отсутствуют.
Сохраняйте каталог репозитория целиком: точка входа импортирует соседние модули
из `src/`. Подключайте локальный путь TypeScript/TSX в TUI-конфигурации OpenCode.

Для глобальной установки скопируйте каталог в глобальную конфигурацию OpenCode
и добавьте точку входа в `~/.config/opencode/tui.json`:

```sh
mkdir -p ~/.config/opencode/plugins
cp -r opencode-session-token-bar ~/.config/opencode/plugins/
```

```json
{
  "$schema": "https://opencode.ai/tui.json",
  "plugin": [
    "./plugins/opencode-session-token-bar/src/index.tsx"
  ]
}
```

Для установки в проекте оставьте плагин в проекте и добавьте тот же
относительный путь в `tui.json` проекта, скорректировав его относительно файла.
Файл [tui.example.json](tui.example.json) содержит готовый глобальный пример.
Если в `tui.json` уже есть массив `plugin`, добавьте элемент, не заменяя другие
плагины.

OpenCode загружает TUI-конфигурацию и плагины только при старте. После установки,
удаления, перемещения или обновления плагина либо `tui.json` завершите и заново
запустите OpenCode.

### Совместимость

В пакете указаны peer dependencies точных версий: `@opencode-ai/plugin` и
`@opencode-ai/sdk` `1.3.17`, `@opentui/core` и `@opentui/solid` `0.1.96`, а
также `solid-js` `1.9.11`. Установите совместимые зависимости в окружении,
которое загружает плагин. Экспорт пакета - `src/index.tsx`; npm-настроек и
переменных окружения у плагина нет.

## Метрики и дерево сессий

Плагин получает значения токенов только из постоянной истории сообщений
ассистента через `session.messages`; отдельные итоги токенов не сохраняются.
Для каждого сообщения ассистента:

- `in hit` - неотрицательное `tokens.cache.read`;
- `in miss` - `max(0, tokens.input - tokens.cache.read)`;
- `out` - неотрицательное `tokens.output`;
- `hit rate` - `in hit / (in hit + in miss)`, либо `0.0%`, если входных токенов
  нет.

Плагин идёт по `parentID` до корня, затем включает транзитивное множество его
потомков. Сводка содержит все эти строки, а в развёрнутом виде строки остаются
разделёнными по точному кортежу агента, провайдера и модели. Имя модели - часть
`modelID` после последнего `/`.

### Скорость стриминга

`session.messages` отдаёт реальные счётчики токенов только на `step-finish`,
поэтому текущая скорость вычисляется из событий `message.part.delta` с
`field === "text"` (и текст, и reasoning используют это поле). Количество
символов (кодовых точек Unicode) хранится в скользящем окне 3 секунды на сессию
и делится на `CHARS_PER_TOKEN` (4). Время от первой дельты ограничено диапазоном
1–3 секунды; после прогрева знаменатель остаётся равным 3 секундам даже при
выходе старых событий из окна. Используются монотонные часы. Новое сообщение
начинает отдельное окно: последовательные ответы и модели не смешиваются.
Сводная строка показывает текущую скорость открытой сессии; развёрнутые строки —
максимальную оценочную скорость на момент прихода дельты, а не среднюю или
итоговую скорость по реальным выходным токенам. Пики привязаны к ID сообщения,
не зависят от порядка истории и учитывают короткие всплески между обновлениями UI.
Ранее сохранённые пики сохраняются и могут отражать старую формулу.

## Персистентность и жизненный цикл

- Состояние развёрнутости хранится локально по ключу
  `session-token-bar.expanded`.
- Активное время хранится для корневой сессии по ключу
  `session-token-bar.active-time.<sessionID>` как `{ elapsed, started? }`.
- Пики хранятся под единым ключом `session-token-bar.peak` как карта
  `rootID -> { ключ строки: пик }`. Запись троттлится при росте пика и
  сбрасывается в `onDispose`. Хранится не более `PEAK_ROOTS_MAX` (20) деревьев,
  вытесняются давно не обновлявшиеся, поэтому значение не растёт бесконтрольно.
- Живые буферы дельт держатся только для сессий открытого дерева панели
  (`message.part.delta`, `field === "text"`). Буфер и привязка строки сессии
  сбрасываются при статусе idle/retry, на `session.idle`, `session.deleted`
  и после прекращения отслеживания последней панелью. Изменённые пики
  сохраняются по таймеру, даже если новые дельты больше не поступают.
- Интервал начинается, когда любая включённая сессия `busy` или `retry`, и
  закрывается, когда все простаивают. Незакрытые интервалы также закрываются в
  `onDispose`.
- При восстановлении устаревший маркер `started` намеренно отбрасывается, чтобы
  не учитывать время, пока OpenCode не работал.
- Итоги токенов всегда восстанавливаются из истории. Удалённая или недоступная
  история не даёт итогов для этой сессии. Аварийное завершение может потерять
  только текущий незакрытый интервал. Хранилище TUI локально и не синхронизируется
  между машинами.

## Тесты

```sh
bun test
bun run typecheck
```

Тесты покрывают агрегацию, группировку по точному кортежу, рекурсивное дерево
сессий, сохранение активного времени и восстановление состояния.

## Ограничения

- Плагин отображается только в TUI OpenCode.
- Скорость стриминга приблизительна: символы делятся на `CHARS_PER_TOKEN`, так
  как реальные токены доступны только на `step-finish`.
- Ожидание пользовательского ввода не считается активным временем.
- Для переключателя требуется поддержка мыши в TUI.
- Плагин не делает сетевых запросов и не обращается к внешним сервисам.
